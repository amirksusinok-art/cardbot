# 💳 Black Cards & VIP Plastic

> **Telegram Mini App** — коллекционная игра о виртуальных премиальных банковских картах, красивых цифровых номерах, редких материалах и оформлении собственной коллекции.

---

## 💎 Особенности проекта

- **Случайный выпуск в один клик:** Нажатие «Выпустить карту» (500 Coins) запускает серверную генерацию карты по фиксированным вероятностям.
- **Эффектная анимация цифр:** 12 отдельных вертикальных колонок цифр вращаются сверху вниз и по очереди останавливаются с haptic-откликом. Редкие карты сопровождаются замедленной драматичной остановкой и золотым свечением. Кнопка «Пропустить» позволяет мгновенно открыть карту.
- **5 вымышленных брендов банков:**
  1. **Рубарис** (Красный, графитовый, металлические акценты)
  2. **Вельтари** (Тёмные поверхности, яркая геометрия)
  3. **Озевия** (Синий, белый, прозрачные градиенты)
  4. **Верданор** (Изумрудный, серебристый, плавные линии)
  5. **Норвиан** (Тёмно-синий, серебро, симметричные узоры)
- **6 реалистичных материалов:**
  - Classic Plastic, Matte Plastic, Gold (24K фольга), Black Carbon (углеволокно), Titanium (шлифованный титан), Holographic (радужный перелив).
- **7 категорий красивых номеров:**
  - Standard, Pair, Triple, Quad, Repeater, Straight, Mirror.
- **Бесплатный режим «БОМЖ»:** Доступен при балансе менее 500 Coins (стоимость 0 Coins, таймер 30 секунд, коэффициент удачи ×0,1).
- **Ежедневные задания:** До 500 Coins в день.
- **Коллекция и Альбомы:** Награды за сбор всех банков, материалов и редких категорий.
- **Магазин Telegram Stars (XTR):** Официальная покупка косметики без случайных наборов (холдеры, рамки, неоновые эффекты цифр, фон Cyber Vault).
- **Профиль и Рейтинг:** Закрепление «Карты дня», витрина до 5 избранных карт, коллекционные ранги и рейтинг лидеров.

## 🔢 Правила определения категорий номеров

Номер карты формируется по стандарту: `2202 • B1 • B2 • B3`, где `B1`, `B2`, `B3` — 4-значные блоки (всего 12 изменяемых цифр).

| Категория | Вероятность (Обычн.) | Вероятность («БОМЖ») | Точное правило генерации и валидации |
| :--- | :---: | :---: | :--- |
| **Mirror** | **1%** | **0.1%** | Зеркальная симметрия: каждый 4-значный блок является палиндромом вида `ABBA` (например, `1221 • 3443 • 5665`) либо весь 12-значный ряд симметричен относительно центра (`ABCDEF FEDCBA`). |
| **Straight** | **2%** | **0.2%** | Непрерывная возрастающая или убывающая последовательность цифр по модулю 10 (например, `1234 • 5678 • 9012` или `9876 • 5432 • 1098`). |
| **Quad** | **2%** | **0.2%** | Как минимум один блок содержит 4 одинаковые цифры подряд (например, `8888 • 3951 • 6208`). |
| **Repeater** | **3%** | **0.3%** | Повторяющийся паттерн: либо блоки вида `ABAB CDCD EFEF` (например, `1212 • 3434 • 5656`), либо повторение одинакового 4-значного блока (`ABCD ABCD ABCD`). |
| **Triple** | **6%** | **0.6%** | Как минимум один блок содержит 3 одинаковые цифры подряд (например, `7771 • 3951 • 6208`), не образуя Quad. |
| **Pair** | **16%** | **1.6%** | Наличие пары одинаковых цифр в блоке (например, `1147 • 3951 • 6208`), без формирования более редких комбинаций. |
| **Standard** | **70%** | **97.0%** | Базовая псевдослучайная цифровая комбинация. |

## 🗄️ Схема базы данных (Render Postgres / SQLite)

### 1. `users`
| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `telegram_id` | `BIGINT PRIMARY KEY` | Уникальный ID Telegram пользователя |
| `username` | `TEXT` | Юзернейм пользователя |
| `first_name` | `TEXT` | Имя пользователя |
| `photo_url` | `TEXT` | Аватар |
| `coins` | `INTEGER DEFAULT 1500` | Баланс игровой валюты Coins |
| `free_mint_available_at` | `BIGINT DEFAULT 0` | Timestamp окончания перезарядки режима «БОМЖ» |
| `equipped_holder` | `TEXT` | Экипированный холдер (`holder_vip`) |
| `equipped_frame` | `TEXT` | Экипированная рамка профиля (`frame_gold`) |
| `equipped_effect` | `TEXT` | Экипированный эффект цифр (`effect_matrix`) |
| `equipped_bg` | `TEXT` | Экипированный фон (`bg_cyber`) |
| `card_of_day_id` | `TEXT` | ID закреплённой карты дня |
| `created_at` | `BIGINT` | Время регистрации |
| `updated_at` | `BIGINT` | Время последнего обновления |

### 2. `cards`
| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | `TEXT PRIMARY KEY` | UUID карты |
| `user_id` | `BIGINT NOT NULL` | Владелец карты |
| `card_number` | `TEXT NOT NULL` | Форматированный номер `2202 • XXXX • XXXX • XXXX` |
| `collection_code` | `TEXT NOT NULL` | Код узора (например, `КОД УЗОРА: 737`) |
| `expiry_date` | `TEXT NOT NULL` | Срок действия `MM/YYYY` (до декабря 2100 г.) |
| `bank` | `TEXT NOT NULL` | Банк: Рубарис, Вельтари, Озевия, Верданор, Норвиан |
| `material` | `TEXT NOT NULL` | Материал карты |
| `category` | `TEXT NOT NULL` | Категория красивого номера |
| `score` | `INTEGER NOT NULL` | Коллекционная оценка (PTS) |
| `is_favorite` | `INTEGER DEFAULT 0` | Флаг избранного (до 5 карт) |
| `is_bomzh` | `INTEGER DEFAULT 0` | Флаг выпуска в режиме «БОМЖ» |
| `created_at` | `BIGINT NOT NULL` | Timestamp выпуска |

### 3. `tasks`
| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | `TEXT PRIMARY KEY` | UUID задания |
| `user_id` | `BIGINT NOT NULL` | Telegram ID игрока |
| `task_key` | `TEXT NOT NULL` | Ключ задачи (`daily_login`, `mint_three`, `daily_quest`) |
| `title` | `TEXT NOT NULL` | Название задания |
| `reward_coins` | `INTEGER NOT NULL` | Награда в Coins |
| `progress` | `INTEGER DEFAULT 0` | Текущий прогресс |
| `target` | `INTEGER NOT NULL` | Целевой показатель |
| `is_claimed` | `INTEGER DEFAULT 0` | Получена ли награда |
| `task_date` | `TEXT NOT NULL` | Дата дня (`YYYY-MM-DD`) |

### 4. `albums`
| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | `TEXT PRIMARY KEY` | UUID записи |
| `user_id` | `BIGINT NOT NULL` | Telegram ID игрока |
| `album_key` | `TEXT NOT NULL` | Ключ альбома (`all_banks`, `all_materials` и др.) |
| `is_claimed` | `INTEGER DEFAULT 0` | Забрана ли награда |
| `claimed_at` | `BIGINT` | Timestamp получения |

### 5. `user_cosmetics` & `transactions`
- `user_cosmetics`: приобретённые товары Stars.
- `transactions`: финансовый аудит списаний, начислений Coins и платежей Stars (`telegram_payment_id`).

## 🌐 Спецификация REST API

| Метод | Эндпоинт | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/me` | Получение профиля, баланса, карты дня, избранного и таймера «БОМЖ» |
| `POST` | `/api/cards/mint` | Транзакционный выпуск новой карты (обычный 500 Coins или БОМЖ) |
| `GET` | `/api/cards` | Получение коллекции с фильтрами (`bank`, `material`, `favorites`) |
| `POST` | `/api/cards/:id/favorite` | Добавление / удаление карты из избранного (до 5 шт.) |
| `POST` | `/api/cards/:id/card-of-day` | Закрепление карты дня в профиле |
| `GET` | `/api/albums` | Список тематических альбомов и текущий прогресс сбора |
| `POST` | `/api/albums/:key/claim` | Получение награды за закрытый альбом |
| `GET` | `/api/tasks` | Список ежедневных задач и их статус |
| `POST` | `/api/tasks/:id/claim` | Забрать награду за выполненное задание |
| `GET` | `/api/shop/items` | Каталог товаров за Stars со статусом владения и экипировки |
| `POST` | `/api/shop/invoice` | Создание официальной ссылки на оплату в Telegram Stars |
| `POST` | `/api/shop/equip` | Экипировка купленного холдера, рамки, эффекта или фона |
| `GET` | `/api/leaderboard` | Рейтинг лучших коллекционеров |
| `GET` | `/api/history` | История последних 30 операций |

## 🚀 Локальный запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/amirksusinok-art/cardbot.git
   cd cardbot
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Скопируйте `.env.example` в `.env`:
   ```bash
   cp .env.example .env
   ```
4. Соберите фронтенд и запустите сервер:
   ```bash
   npm run build
   npm start
   ```
5. Откройте в браузере: `http://localhost:3000`
